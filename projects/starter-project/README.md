# Starter Project — Milestone de Integración (Inverted PBL)

Este directorio es el hogar del proyecto práctico que se construye semana a semana.

## Filosofía
- **Inverted Project-Based Learning:** Los conceptos teóricos de lunes a viernes no se aprenden en abstracto, sino para desbloquear los requerimientos de este proyecto.
- **Sábado de Milestone:** Cada sábado se avanza una versión/feature del proyecto (`v1.0`, `v1.1`, etc.) integrando lo visto durante la semana.

## Estructura
- `src/`: Código fuente del proyecto.
- `docs/`: Arquitectura, diagramas, pseudocódigo y especificaciones funcionales.
